# Bythos — Landing (React + plain CSS)

Single-file landing modularized into Vite + React with plain CSS per component.
Visual style preserved 1:1 from the reference HTML file (frozen, no redesign).

## Install

```bash
npm install
```

## Run (dev)

```bash
npm run dev -- --host
```

## Build

```bash
npm run build
```

## Preview (production smoke check)

```bash
npm run preview
```
